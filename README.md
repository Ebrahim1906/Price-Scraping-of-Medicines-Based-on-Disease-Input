# Price-Scraping-of-Medicines-Based-on-Disease-Input
A Python-based web scraping tool that retrieves medicine prices by entering disease names (e.g., cough, fever). The system extracts available medicine brands and their per-unit prices and visualizes the data using graphical representations to help users compare prices and choose cost-effective options.

📌 Project Overview
Healthcare costs vary significantly depending on the medicine brand. This project provides a simple solution for users to:
Search medicines based on disease names
Automatically scrape medicine price information
Compare prices across multiple brands
Visualize price differences using graphs
